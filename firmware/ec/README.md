# Orion O6 EC firmware (ITE IT5570E)

Open firmware for the Orion O6's embedded controller, written after
Radxa's EC V1.07 and compared with it in an emulator.  See
[docs/open-firmware.md](../../docs/open-firmware.md#ec-firmware-orion-o6);
every way it differs from the vendor's image is in
[differences.md](differences.md).

    make [O=dir]        # build/ec_fw.bin: 128 KiB e-flash image (SDCC 4.2-4.6)
    ./build.sh orion-o6 --open-ec   # (repository root) into the flash image
    E=emu/target-ec/release/sky1emu # (repository root) cargo build --release --manifest-path emu/Cargo.toml --features ec --target-dir emu/target-ec
    $E ec-test --open firmware/ec/build/ec_fw.bin [-v] [scenario...]   # ~35 s
    $E ec-test --open firmware/ec/build/ec_fw.bin --cov ec.cov && $E ec-cov ec.cov firmware/ec/build --partial --lines

`src/`: `vectors.s` (vectors, ITE signature at 0x40), `main.c` (tick,
hooks), `power.c` (sequencer tables, button, the SoC's sleep signals:
suspend, resume, shutdown), `host.c` (SMBus B slave, host commands),
`fan.c` (NTCs, CSU_PM temperature, fan states, the trip), `pd.c`
(RTS5453H set-up), `led.c` (the power LED, breathing in suspend),
`smbus.c`, `eflash.c` + `scratch*.c` (e-flash writes from scratch ROM,
mirror reset), `gpio.c` (the O6 pin table), `ntc_table.h` (generated by
`sky1emu ec-ntc-table VENDOR.bin src/ntc_table.h` from the vendor image's
own conversion routine).

Not hardware-tested.  The image only reaches the EC through UEFI's
platform reset (host command 0x3E19), which mirrors the SPI copy into the
e-flash.
